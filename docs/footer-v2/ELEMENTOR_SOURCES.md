# Elementor : liste des sources consultées

Date d'accès de toutes les pages : **9 novembre 2026**. Méthode : les pages ont été lues avec l'outil WebFetch (qui renvoie un résumé produit par un petit modèle, pas la page brute) ; les pages du centre d'aide Elementor contiennent ~100 000 caractères de menu, donc le corps de l'article a été lu en lisant la suite de la page (« offset 100000 »). **Aucune interface Elementor réelle n'a été ouverte** : aucune affirmation n'est « OBSERVÉE ».

Légende de fiabilité de la source : **LU** = corps de l'article lu ; **EXTRAIT** = seulement un extrait de résultat de recherche (confiance réduite, à revérifier) ; **INUTILISABLE** = page demandée mais contenu inexploitable ; **BLOQUÉ** = refusé par l'outil de sécurité.
