# Pieds de page (footers) étudiés : références réelles

Étude du 9 novembre 2026. Branche `footer-v2-etude`. Aucune copie de texte ou d'image protégée : ce sont des **notes d'observation** pour s'inspirer (principes et finitions), pas pour recopier.

## Comment lire ce document

- **VU** : j'ai chargé la page dans un vrai navigateur (Chrome sans fenêtre), j'ai fait défiler jusqu'en bas, pris une capture et **regardé l'image**. Les captures sont hors dépôt (dossier indiqué plus bas).
- **VU partiel** : capture regardée, mais un bandeau de cookies, une fenêtre pop-up ou un chargement en cours cache une partie du pied de page.
- **LU** : je n'ai pas vu l'image ; j'ai lu le texte et le style relevés dans la page rendue (couleurs, polices, liens) ou un article qui décrit le pied de page. Ce que j'écris se limite à ce texte.
- **NON VÉRIFIÉ** : page bloquée, vide, payante ou non atteinte. Je n'invente rien : c'est dit.
- Les nombres de ventes ThemeForest sont ceux affichés par la page « WordPress, tri meilleures ventes » de themeforest.net le 9/11/2026.
- Dossier des captures (hors dépôt) : `/private/tmp/claude-501/-Users-imac-Downloads-Ptojry-google-stich-design/234805b0-e56d-4b6e-a957-09d5db8adc8d/scratchpad/marketplaces/` (fichier = `<identifiant>.png`, version téléphone = `<identifiant>-m.png`).
