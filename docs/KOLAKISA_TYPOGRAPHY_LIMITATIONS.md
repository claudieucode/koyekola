# Typographie Kolakisa — limites

- Arial n'est pas fournie par le site : un système sans Arial, Helvetica ni Liberation Sans/Arimo retombera sur la sans-serif par défaut (rendu proche mais pas identique).
- Les thèmes de la bibliothèque et les sites déjà personnalisés gardent leurs polices : l'identité Arial s'applique aux défauts, pas aux choix existants.
- Arial n'a pas de graisse 800 : les titres « extra-gras » passent à 700.
- Pas de capture avant/après de chaque écran de l'administration (connexion requise) : contrôle automatisé des feuilles + mesure sur page de référence (voir rapport de test).
- Les contenus HTML déjà écrits avec `font-family` en ligne (éditeur d'articles) ne sont pas réécrits.
