# KOLAKISA — Parcours utilisateur de l'Assistant IA

1. **Accueil des projets** (`/marketing/ia/studio`) : « Reprendre mon travail » (dernier projet, progression réelle), liste groupée (en cours, en attente, plan validé, publiés), formulaire « Nouveau projet ». Le texte en cours de saisie est conservé dans le navigateur.
2. **Décrire** (minimum : quelques phrases) et choisir un **nouveau site** (créé en brouillon) ou un **site existant**. L'analyse peut échouer (IA indisponible, quota) : le message est expliqué, le texte conservé, aucun site actif orphelin.
3. **Brief** : questions facultatives → plan.
4. **Plan** : relire, modifier, accepter/refuser les suggestions, **valider**. Annuler / Rétablir à tout moment.
5. **Pages** : générer → voir la proposition → appliquer en brouillon (rien n'est publié).
6. **Design** : choisir une direction, comparer, appliquer (au brouillon du personnalisateur).
7. **Contenus**, **Images** : compléter ; les textes d'exemple restent entre crochets tant qu'ils ne sont pas remplacés.
8. **Prévisualiser** sur les trois largeurs.
9. **Publier** quand la liste de contrôle ne contient plus d'erreur bloquante.
À tout moment : demander à l'assistant (« Ajoute une page À propos ») → **proposition** → Accepter ou Refuser.

## Reprise
Fermer l'onglet ne perd rien : chaque action est enregistrée côté serveur avant d'être affichée comme enregistrée. « Reprendre mon travail » rouvre le projet à sa dernière étape (mémorisée dans le navigateur) ou à l'étape réelle suivante.
