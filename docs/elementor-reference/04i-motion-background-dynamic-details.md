# 04i — Mouvement, arrière-plans, contenu dynamique, formulaire atomique

_Articles lus le 2026-10-10._

- **Effets au survol** (/help/hover-effects/, /help/hover-animations/) : au niveau widget, colonne, section, combinables. **14 animations de survol** : Grow, Shrink, Pulse, Push, Pop, Bounce, Rotate, Float, Sink, Bob, Hang, Skew, Wobble, Buzz (aucun réglage détaillé).
- **Animations d'entrée** (/help/entrance-animations/) : Avancé → Effets de mouvement ; **37 animations en 8 groupes** (fondu, zoom, rebond, glissement, rotation, attirer l'attention, vitesse de la lumière, spéciaux) avec variantes haut/bas/gauche/droite ; réglables **par appareil** (y compris « aucune ») ; désactivées si l'utilisateur réduit les animations ; durée et délai non mentionnés dans l'article.
- **Effets de souris** (/help/mouse-effects-3d-tilt/, /mouse-track/) : **Inclinaison 3D** et **Suivi de la souris** — direction (opposée / directe), vitesse 0–10, appareils, relatif à (défaut, fenêtre, page entière). Pro : non tranché.
- **Sticky** (/help/sticky-scrolling-effect-pro/) : aucun / haut / bas, appareils, décalage (px), décalage des effets, rester dans la colonne. Pro.
- **Diaporama en arrière-plan** (/help/background-slideshow/) : images, boucle infinie, durée (ms), transition (fondu, glissement 4 sens), durée de transition, taille, position, **Ken Burns** (zoom avant / arrière).
- **Vidéo en arrière-plan** (/help/section-background-video-options/) : YouTube / Vimeo / auto-hébergée, début / fin, lecture unique, **image de secours**, lecture sur mobile, mode confidentialité (YouTube), voile.
- **Rayon de bordure** (/help/border-radius-tools/) : unités px, %, em, rem, vw, perso (variables CSS) ; valeurs liées / indépendantes par coin ; cercle = 50 % ; « pilule » = 999 px.
- **Accordéon avec éléments imbriqués** (/help/accordion-widget-with-nested-elements/) : chaque élément contient un conteneur (images, boutons, widgets) ; état par défaut, **nombre maximal d'éléments ouverts**, durée d'animation, schéma FAQ ; **absorbe le widget Bascule** ; incompatible avec la boucle ; ID CSS impossible.
- **Étiquettes dynamiques** (/help/dynamic-tags-pro-2/) : *Article* (champ perso, extrait, ID, termes, heure, titre, URL), *Archive* (description, méta, titre, URL), *Site* (titre de page, slogan, titre du site, **date et heure courantes, paramètre de requête, shortcode, infos utilisateur, URL du site, URL interne**), *Actions* (**visionneuse, URL de contact, fenêtre contextuelle**), *Média* (image mise en avant : titre, alt, légende, description, URL), *Auteur* (bio, e-mail, site, méta, nom, URL), *Commentaires*, *WooCommerce*, ACF (non lu). Pro : non tranché.
- **Formulaire atomique (V4)** (/help/atomic-form-element/) : états Normal / Succès / Erreur ; actions : e-mail, **e-mail 2 (Pro, auto-réponse)**, collecte des envois ; champs : étiquette, entrée (texte, e-mail, nombre, tél., mot de passe ; requis, lecture seule, saisie automatique), zone de texte (lignes, min/max), cases, radios (groupe), **date** (min/max), **heure** (début/fin), liste (valeur affichée / envoyée, multiple), **fichier** (lien / pièce jointe / les deux, taille max, types, multiple) ; bouton ; chaque atome : ID, attributs, conditions d'affichage.
