# 04b — Réglages des widgets (suite, partie 1)

_Articles lus le 2026-10-10 (corps après décalage 100 000). Statut gratuit/Pro : l'article ne le dit presque jamais ; les « tags de plan » dans les métadonnées ne permettent pas de conclure. Le suffixe `-pro` dans l'adresse est un indice, pas une preuve. La colonne « KOLAKISA » est ajoutée dans `18-…`._

## Alerte — /help/alert-widget/
Type (Info, Succès, Avertissement, Danger), titre, contenu, icône de fermeture (afficher/masquer) + icône (défaut, SVG, bibliothèque). Style : fond, couleur et largeur de la bordure gauche ; titre et description (couleur, typographie, ombre) ; icône de fermeture (normal/survol, durée, taille, position verticale haut/milieu/bas, horizontale gauche/centre/droite, couleur).

## Titre animé — /help/animated-headline-pro/
Style « Surligné » (formes : cercle, ondulé, souligné, double, double souligné, zigzag, diagonale, barré, X) ou « Rotatif » (Frappe, Clip, Flip, Tourbillon, Stores, Chute, Vague, Glissement, Glissement bas) ; texte avant / animé / après ; boucle infinie, durée (ms), délai (ms, surligné seulement) ; lien ; alignement ; balise H1–H6, div, span, p. Style : forme (couleur, épaisseur, devant, bords arrondis), textes (couleur, typographie, **contour du texte**).

## Citation — /help/blockquote-widget-pro/
Habillages : Bordure, Guillemets, Encadré, Épuré ; alignement ; contenu (étiquettes dynamiques) ; auteur ; **bouton Tweet** (vue icône/texte, habillage classique/bulle/lien, étiquette, identifiant, URL cible) ; style complet (texte, écart, auteur, bouton normal/survol, bordure, guillemets, encadré : padding, fond, bordure, rayon, ombre, transition).

## Fil d'Ariane — /help/breadcrumbs-widget-pro/
Alignement, balise (div, span, nav, p), typographie, couleur du texte, couleur des liens (normal/survol). **Dépend de l'extension Yoast SEO.**

## Appel à l'action — /help/call-to-action-widget/
Habillage Classique (position de l'image gauche/dessus/droite) ou Couverture ; élément graphique (aucun, image, icône avec vue par défaut/empilée/encadrée, cercle/carré) ; résolution de l'image ; titre + balise, description + balise (H1–H6, div, span) ; texte du bouton ; lien (nofollow, nouvelle fenêtre) ; **appliquer le lien sur : boîte entière ou bouton seul** ; **bandeau** (titre, gauche/droite). Style : hauteur, alignement, position verticale, padding ; image ; titre (contour) ; couleurs ; bouton complet ; ruban ; effets de survol (animation, voile, filtres CSS, mode de fusion, durée ; Couverture : animation du contenu, durée, animation séquencée).

## Carrousel (conteneurs imbriqués) — /help/carousel-widget/
Éléments, diapositives affichées / défilées, hauteurs égales ; lecture auto, vitesse, pause au survol / à l'interaction, boucle, durée de transition, direction, **diapositives décalées** (aucune, deux côtés, gauche, droite) ; flèches (icônes, position H/V) ; pagination (points, fraction, barre de progression, aucune). Style : écart, fond, bordure, rayon, padding ; navigation (taille, couleurs, fond, ombre, position intérieur/extérieur) ; pagination (taille, position libre, espace).

## Code Highlight — /help/code-highlight-pro/
Plus de 50 langages, code (étiquette dynamique), numéros de ligne, bouton Copier, **lignes surlignées** (plages « 2-7, 10 »), retour à la ligne, thème clair/sombre, hauteur, taille de police.

## Compte à rebours — /help/countdown-widget-pro/
Type Date fixe ou **Minuteur évolutif (par visiteur)**, date, heures/minutes (étiquettes dynamiques), vue bloc/en ligne, jours/heures/minutes/secondes, étiquettes personnalisées, **action à l'expiration : rediriger, masquer, afficher un message**. Style : boîtes (largeur, fond, bordure, rayon, espace, padding), chiffres, étiquettes, message.

## Compteur — /help/counter-widget/
Début, fin, préfixe, suffixe, durée d'animation (ms), séparateur de milliers (défaut, point, espace), titre + balise (H1–H6, div, span, p). Style : position du titre (dessus, dessous, droite, gauche), alignement, écart, position du nombre (droite, gauche, centre, étiré), couleur, typographie, **contour**, ombre.
