# 04g — Réglages des widgets (suite, partie 6 : contenu dynamique du site)

_Articles lus le 2026-10-10._

- **Grille de boucle (Loop Grid)** (/help/loop-grid/) : type de modèle (articles, taxonomie d'article, produits, taxonomie de produit), modèle, colonnes, éléments par page, **mosaïque**, hauteurs égales, **modèle alterné** ; requête (source, inclure / exclure, date, masquer les vides, profondeur, tri, ID de requête) ; **pagination** (numéros, précédent/suivant, les deux, charger au clic, défilement infini ; limite de pages ; rechargement de page ou AJAX ; pagination individuelle) ; message « rien trouvé ».
- **Carrousel de boucle** (/help/loop-carousel/) : mêmes réglages de requête ; éléments visibles / défilés, hauteurs égales, lecture auto, boucle, flèches, pagination (points, fraction, progression).
- **Filtre de taxonomie** (/help/taxonomy-filter-widget/) : grille de boucle cible, taxonomie, direction, alignement ; logique (sélection multiple et/ou) ; éléments vides, enfants, premier élément « Tous », nombre, défilement horizontal ; états normal / survol / actif.
- **Articles (Posts)** (/help/posts-widget-pro/) : habillages **Classique, Cartes, Contenu complet** ; colonnes 1–6, extrait + longueur, méta-données, « lire la suite », badge de taxonomie, avatar ; requête (articles, pages, pages d'atterrissage, types personnalisés, manuel, requête courante, associés) ; pagination (aucune, numéros, précédent/suivant, charger au clic, défilement infini).
- **Image mise en avant** (/help/featured-image-widget/) : image de l'article (image de repli), résolution, légende (aucune / pièce jointe / perso), lien (aucun, fichier avec visionneuse, URL) ; largeur, largeur max, hauteur, opacité, filtres, survol, bordure, ombre.
- **Boîte d'auteur** (/help/using-the-author-box-widget/) : source (courant / perso), photo (taille), nom + balise, lien, biographie, bouton d'archive ; disposition (photo gauche / droite / dessus).
- **Infos de l'article** (/help/post-info-widget/) : disposition par défaut / en ligne ; éléments **auteur, date, heure, commentaires, termes, personnalisé** (texte avant, avatar, lien, icône, format) ; séparateur.
- **Navigation d'article** (/help/post-navigation-widget/) : étiquettes précédent / suivant (dynamiques), flèches (type), titre, bordures, **dans le même terme**.
- **Commentaires d'article** (/help/post-comments-widget/) : habillage « commentaires du thème » seulement, source article courant / perso. Les commentaires doivent être autorisés dans WordPress.
- **Logo du site** (/help/site-logo-widget-pro/) : logo de l'identité du site, résolution, légende, lien (aucun, fichier avec visionneuse, URL perso, **URL du site**) ; largeur, hauteur, ajustement, survol, bordure, ombre.
