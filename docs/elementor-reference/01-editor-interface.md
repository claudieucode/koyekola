## Menus contextuels — confirmé
Source : https://elementor.com/help/right-click/ (article lu). Clic droit sur l'onglet d'un conteneur ou le coin d'un widget.
- **Conteneur** : Modifier, Dupliquer, Ajouter un conteneur, Copier, Coller, Coller le style, Coller depuis un autre site, Réinitialiser le style, Modifier avec l'IA, Enregistrer comme modèle, Enregistrer par défaut, Notes, Structure, Supprimer.
- **Widget** : Modifier, Dupliquer, Copier, Coller, Coller le style, Coller depuis un autre site, **Coller / effacer les conditions d'affichage**, Réinitialiser le style, **Enregistrer comme global**, Enregistrer par défaut, Notes, Structure, Supprimer.
- Section et colonne (éditeur historique) : mêmes actions de copie/style, plus Enregistrer comme modèle (section).
- Ctrl/Cmd + clic droit : menu natif du navigateur. Sur Mac, « clic secondaire » doit être activé.
- Étiquettes Pro : l'article n'en marque aucune (« Enregistrer comme global » pointe vers une page « pro » : **à vérifier**).

## Navigator / Structure — partiellement confirmé
Ouverture : clic droit → Structure, icône « calques » du pied de panneau, ou Ctrl/Cmd+I (blog « Introducing Navigator »). Les actions du menu contextuel fonctionnent aussi dans le Navigator. Détail de l'article Navigator : **non lu**.
