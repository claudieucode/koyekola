# 04c — Réglages des widgets (suite, partie 2)

_Articles lus le 2026-10-10 (corps, décalage 100 000). Gratuit/Pro non indiqué sauf mention._

- **Séparateur** (/help/divider-widget/) : style classique ou à motifs (plein, ondulé, tribal, flèches, plus…), largeur 0–100 %, alignement, élément ajouté (aucun, texte, icône). Style : couleur, épaisseur 1–100 (px/%), quantité, écart ; texte (couleur, typographie, position, espacement) ; icône en vue Défaut / Empilée / Encadrée (taille, padding, couleurs, position, espacement, **rotation 0–360**, bordure, rayon).
- **Espaceur** (/help/spacer-widget/) : un curseur de hauteur, unités px, em, rem, %, vw, vh. (Masque et remplissage mentionnés sans détail.)
- **Flip Box** (/help/flip-box-widget-pro/) : face avant / arrière (élément graphique, titre, description, fond couleur/image/dégradé avec attachement, répétition, taille, voile), bouton + lien + « appliquer sur : bouton seul / boîte entière » ; effet **Flip, Slide, Push, Zoom avant/arrière, Fondu**, direction, profondeur 3D, hauteur, rayon. Style complet des deux faces et du bouton (tailles XS→XL, normal/survol, dégradé).
- **Points d'intérêt (Hotspot)** (/help/hotspot-widget-pro/) : image (résolution, alignement) ; chaque point : étiquette, lien (dynamique), icône, taille perso, **contenu d'infobulle (HTML)**, position H/V en %, position/largeur d'infobulle perso, retour à la ligne, animation, séquence ; infobulle : position (4), **déclencheur survol / clic**, animation, durée. Style : fond (largeur, hauteur, opacité), point (couleur, taille, typographie, boîte, padding, rayon, ombre), infobulle (texte, alignement, boîte).
- **Icon Box** (/help/icon-box-widget/) : icône (bibliothèque ou SVG), vue (défaut/empilée/encadrée, cercle/carré), titre, description, lien (nouvelle fenêtre, nofollow, **attributs personnalisés clé|valeur**), balise du titre. Style : position de l'icône (gauche/haut/droite), alignement, espacements, icône normal/survol (couleurs, taille, rotation, **animation au survol**), titre (contour, ombre), description.
- **Liste d'icônes** (/help/icon-list-widget/) : disposition **défaut (verticale) ou en ligne**, éléments (texte dynamique, icône, lien avec options), appliquer le lien (pleine largeur / en ligne). Style : espace entre éléments, alignement, **séparateur (plein, double, pointillé, tirets ; épaisseur, largeur, couleur)**, icône (couleur normal/survol, taille, écart, alignements, décalage vertical), texte (typographie, ombre, couleur normal/survol, transition).
- **Icône** (/help/icon-widget/) : icône, vue, forme, lien, alignement ; style : couleurs, taille, **rotation**, padding, rayon, normal/survol, animation de survol (Grow, Pulse, Skew…).
- **Carrousel d'images** (/help/image-carousel-widget/) : images, résolution, 1–10 diapositives visibles, diapositives défilées, étirement, navigation (flèches, points, les deux, aucune), lien (fichier avec visionneuse oui/non, URL perso avec attributs, aucun), légende (aucune, titre, légende, description), chargement différé, lecture auto, pause, boucle, vitesse, direction. Style : flèches (position, taille, couleur), points, alignement vertical, espacement, bordure, rayon, légende.
- **Lottie** (/help/lottie-widget/) : source URL externe ou fichier `.json`, alignement, légende, lien, **déclencheur : fenêtre, clic, survol (zone), défilement, aucun**, boucle (défaut, pause, inverse), vitesse, point de départ / fin, inverser, moteur SVG ou Canvas, chargement différé. Style : largeur, largeur max, opacité, filtres CSS.
- **Ancre de menu** (/help/menu-anchor-widget/) : un nom d'ancre (A–Z a–z 0–9 _ -), invisible, lien `#nom`, **même page seulement**.
