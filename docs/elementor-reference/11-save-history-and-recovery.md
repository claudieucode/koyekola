# 11 — Enregistrement, historique et récupération

_Vérifié le 2026-10-10._
- **Historique (Actions)** : liste toutes les actions de la session d'édition ; cliquer sur une entrée ramène la page à cet état. **Révisions** : une révision est créée à chaque enregistrement ou publication ; cliquer rétablit cette version. Source : https://elementor.com/help/revision-history-undo-and-redo/ (article lu). Ouverture : Ctrl/Cmd+Maj+H.
- **Annuler / rétablir** : Ctrl/Cmd+Z, Ctrl/Cmd+Maj+Z.
- **Enregistrement automatique** : introduit en v1.9 ; les enregistrements automatiques apparaissent comme révisions (blog https://elementor.com/blog/autosave/ ; article d'aide non lu).
- **Effacement** : sur un site hébergé par Elementor, l'historique des révisions peut être effacé depuis MyElementor — **définitif** (résultat de recherche).
- Page « actions irréversibles » (https://elementor.com/help/undo-changes-history-and-irreversible-actions/) : **non lue**.
## Non vérifié
Limite du nombre de révisions, indicateur d'état d'enregistrement, modifications concurrentes (verrouillage d'édition entre utilisateurs).
