# 04 — Réglages des widgets lus en détail

_Vérifié le 2026-10-10. Chaque section cite l'article lu (décalage 100 000 caractères). Le statut gratuit/Pro n'est donné que s'il est écrit dans l'article._

## Image — https://elementor.com/help/image-widget/
- **Contenu** : Choisir l'image (téléversement, médiathèque ou **étiquette dynamique** : image mise en avant, logo, photo d'auteur) ; **Résolution de l'image** (miniature, taille complète ou taille personnalisée) ; Alignement ; Légende (aucune, celle de la médiathèque, ou personnalisée) ; Lien (fichier média, URL personnalisée, aucun) ; Lightbox (Oui/Non, remplace le réglage du site, seulement si le lien pointe vers le fichier) ; options de lien : nouvelle fenêtre, nofollow, attributs personnalisés clé-valeur.
- **Style** : Largeur et largeur max ; Hauteur et **Object Fit** (Remplir, Couvrir, Contenir) ; Opacité et filtres CSS (flou, luminosité, contraste, saturation) ; Survol : durée de transition et animation ; Bordure et rayon ; Ombre.

## Image Box — https://elementor.com/help/image-box-widget/
Contenu : image, résolution (miniature/complète/personnalisée), titre, description, lien (nouvelle fenêtre, nofollow), balise du titre (H1–H6, div, span, p). Style : position de l'image (gauche, haut, droite ; centrée sur mobile), alignement (y compris justifié), espacement image/contenu, largeur 0–100 %, bordure et rayon, Normal/Survol (filtres, opacité, transition), titre (couleur, typographie, contour, ombre), description. Aucune mention Pro.

## Galerie — https://elementor.com/help/gallery-widget/
Type : Simple ou Multiple (galerie filtrable). Images : médiathèque ou étiquettes dynamiques (pièces jointes, ACF, produits WooCommerce — cette dernière source renvoie vers un article Pro). Disposition : **Grille** (ratio d'aspect 1:1, 3:2, 4:3, 9:16, 16:9, 21:9), **Justifiée** (hauteur de ligne), **Maçonnerie**. Colonnes 1–24 (pas en justifiée). Ordre (défaut/aléatoire), chargement différé, espacement, lien (aucun, fichier, URL), **résolution de l'image**. Surcouche au survol (titre/description issus de titre, légende, alt, description), dégradé, modes de fusion, animations. Barre de filtres (Multiple seulement) : « Tous », style de pointeur. Lightbox : non traité par cette page.

## Bouton — https://elementor.com/help/button-widget/
Type (Défaut, Info, Succès, Avertissement, Danger), texte, lien (nouvelle fenêtre, nofollow), icône (bibliothèque ou SVG) + position + espacement, **ID du bouton** (suivi analytique). Style : alignement (y compris justifié), typographie, ombre du texte, Normal/Survol (couleurs, animation, transition), bordure (type, largeur, couleur, rayon), ombre, padding.

## Titre — https://elementor.com/help/heading-widget/
Titre, lien, **balise HTML** (H1–H6, div, span, p ; changer la balise ne change pas le style), alignement, couleur, typographie, contour du texte, ombre du texte, **mode de fusion**.

## Accordéon — https://elementor.com/help/accordion-widget/
Éléments (titre, contenu), icône d'ouverture et icône active (aucune, SVG, bibliothèque), balise du titre (H1–H6, DIV), **schéma FAQ** (balisage activable). Style : bordures, titre (fond, couleur, couleur active, typographie, contour, ombre, padding), icône, contenu.

## Formulaire — https://elementor.com/help/form-widget/
Champs : Texte, E-mail, Zone de texte, URL, Téléphone, Radio, Sélection, Cases, Nombre, Date, Heure, Mot de passe, Caché, HTML, Acceptation, Étapes. Fichiers : sur le serveur, en pièce jointe ou les deux. Actions après envoi : fenêtre contextuelle, e-mail, service tiers, redirection. Anti-spam : reCAPTCHA, reCAPTCHA v3, honeypot. Gratuit/Pro : **non indiqué** par l'article.

## Non vérifié
Tous les autres widgets (texte, vidéo, carrousels, onglets, menu, compteur, etc.).
