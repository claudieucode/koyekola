# 04d — Réglages des widgets (suite, partie 3)

_Articles lus le 2026-10-10. Gratuit/Pro non indiqué sauf mention._

- **Liste de prix** (/help/price-list-widget-pro/) : éléments (prix, titre, description, balises, image, lien), séparateur (plein, pointillé, tirets, double, aucun ; épaisseur, couleur, espacement), image (résolution, rayon), écart des lignes, alignement vertical.
- **Tableau de prix** (/help/price-table-pro/) : en-tête (titre, description, balise H2–H6), tarif (symbole préréglé ou personnalisé, prix, format des milliers, **promotion : ancien prix barré**, période), liste de fonctionnalités (texte, icône, couleur), pied (bouton, lien, info), **bandeau** (haut gauche / droite). Style très détaillé (fonds, paddings, typographies, séparateurs, bouton XS→XL normal/survol).
- **Barre de progression** (/help/progress-bar-widget/) : titre + balise, pourcentage, affichage du pourcentage, texte intérieur ; couleur, fond, texte intérieur, titre.
- **Suivi de progression** (/help/progress-tracker/) : type **horizontal ou circulaire**, relatif à **la page entière / au contenu de l'article / à un sélecteur**, direction, pourcentage ; style : taille, indicateur, fond du suivi, pourcentage. Avancé : positionnement et sticky.
- **Évaluation** (/help/rating-widget/) : échelle (plus de 10 possible), note entière ou **demi**, icône (bibliothèque ou SVG), alignement ; taille, espacement, couleur des symboles remplis / vides.
- **Lire la suite** (/help/read-more-widget/) : un seul champ « texte du lien ».
- **Avis (Reviews)** (/help/reviews-widget-pro/) : éléments (image, nom, titre, note 0–5, icône, lien, avis), 1–10 visibles, défilement, largeur, flèches, pagination (aucune, points, fraction, progression), durée, lecture auto, boucle, pause, résolution d'image, chargement différé. Style complet.
- **Formulaire de recherche** (/help/search-form-widget/) : habillages Classique / Minimal / Plein écran, texte indicatif, bouton icône ou texte. **Remplacé par le widget « Recherche » depuis Elementor 3.24** (les anciens restent modifiables).
- **Boutons de partage** (/help/share-buttons-widget-pro/) : réseaux (liste non détaillée sur la page), étiquette perso, vue (icône + texte / icône / texte), habillage, forme, colonnes, alignement, URL cible (page courante ou perso, étiquettes dynamiques) ; couleurs officielles ou perso normal/survol. X et Threads ajoutés.
- **Icônes sociales** (/help/social-icons-widget/) : éléments (icône, lien, couleur officielle/perso), forme (arrondie, carrée, cercle), colonnes (auto, 1–6), alignement ; couleur, taille, padding, espacement, écart des lignes, bordure, rayon, survol avec animation.
