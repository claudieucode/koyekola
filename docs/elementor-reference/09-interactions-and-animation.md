# 09 — Interactions et animations

_Vérifié le 2026-10-10 (résultats de recherche elementor.com ; articles complets **non lus**)._
- **Effets de mouvement** (Avancé) : Effets de défilement (vertical, horizontal, transparence, flou, rotation, échelle — Pro), Effets de souris, Sticky (Pro), Animation d'entrée (fondu, zoom, rebond, glissement, rotation ; réglable par appareil). Sources : https://elementor.com/help/motion-effects/, /entrance-animations/, /scrolling-effects-vertical-scroll/.
- **Accessibilité** : les effets de mouvement sont désactivés pour les utilisateurs qui ont activé la réduction des animations dans leur système (indiqué dans les résultats de recherche).
- **Conflit connu** : animations d'entrée + effets de souris peuvent faire disparaître des éléments dans Safari ; remède officiel : retirer l'un des deux.
- **Sticky** : en v3 sous Avancé → Effets de mouvement → Sticky (haut/bas, appareils, décalage) ; en V4 sous Style → Position.
- **V4 — Interactions** (4.0, Pro) : déclencheurs au chargement, à l'entrée dans la vue, au survol, au clic ; effet personnalisé.
- **États** : survol, focus, actif ; état « Selected » pour les déclencheurs d'onglet (3.34). Source : https://elementor.com/help/element-states/ (non lu en détail).
## Non vérifié
Transitions, accessibilité clavier des widgets interactifs, comportement mobile.
