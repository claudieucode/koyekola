# 04e — Réglages des widgets (suite, partie 4)

_Articles lus le 2026-10-10. Gratuit/Pro : seul « Onglets avec éléments imbriqués » est dit Pro (et nécessite l'expérience « Nested Elements »)._

- **Onglets** (/help/tabs-widget/) : éléments, position horizontale/verticale, alignement (début, centre, fin, étirer) ; bordure, fond, titre (couleur, active, typographie, contour, ombre), contenu.
- **Onglets imbriqués** (/help/tabs-with-nested-containers/) : titres avec icône + icône active, direction colonne/ligne, justification, alignement du titre, **défilement horizontal**, **point de rupture du passage en vertical** (mobile < 767, tablette < 1024, aucun) ; style : écart, distance au contenu, fond/bordure normal-survol-actif, ombre, rayon, padding, icône (position, taille, espacement, couleurs). « L'ID CSS ne peut pas être utilisé avec ce widget. »
- **Bascule** (/help/toggle-widget/) : éléments, icône + icône active, balise du titre, **schéma FAQ (un seul widget par page)** ; bordure, espacement, ombre, titre (fond, couleur, active, padding), icône, contenu.
- **Témoignage** (/help/testimonial-widget/) : texte, image (résolution), nom, fonction, lien (attributs personnalisés), **position de l'image (dessus, gauche, droite)**, alignement ; image (bordure, rayon), textes.
- **Carrousel de témoignages** (/help/testimonial-carousel-pro/) : habillage Défaut / **Bulle**, disposition (image en ligne, empilée, dessus, gauche, droite), 1–10 visibles, flèches, pagination, lecture auto, boucle, pauses, résolution, chargement différé.
- **Éditeur de texte** (/help/text-editor-widget/) : texte (images et shortcodes), **lettrine (drop cap)**, **colonnes**, écart des colonnes ; alignement (y compris justifié), couleur, typographie, ombre ; lettrine : vue défaut/empilée/encadrée, couleur, ombre, espace, rayon, typographie.
- **Texte sur chemin (Text Path)** (/help/text-path-widget/) : texte, type de chemin **Vague, Arc, Cercle, Ligne, Ovale, Spirale, Personnalisé (SVG)**, lien, alignement, direction (défaut, RTL, LTR), afficher le chemin ; taille, rotation, typographie, espacement des mots, point de départ, couleurs normal/survol, trait.
- **Vidéo** (/help/video-widget/) : sources YouTube, Vimeo, Dailymotion, VideoPress, **auto-hébergée** ; début/fin (s), lecture auto (+ mobile pour YouTube), muet, boucle, contrôles, sous-titres, marque discrète, suggestions, **mode confidentialité (YouTube, Vimeo)**, **chargement différé**, extras Vimeo / Dailymotion, bouton de téléchargement, préchargement, affiche ; **image de recouvrement + icône de lecture**, **visionneuse**. Style : ratio (1:1, 4:3, 16:9…), filtres CSS, icône de lecture.
- **Playlist vidéo** (/help/video-playlist-widget-pro/) : éléments YouTube / Vimeo / auto-hébergé / section, données vidéo, durée, vignette, onglets de contenu, repliable (étiquettes lire plus/moins, hauteur), image de recouvrement, lecture auto (au chargement / suivante), indicateur « vu », compteur ; position de la liste gauche/droite, barre du haut, éléments, sections, onglets.
- **Diaporama (Slides)** (/help/slides-widget-pro/) : par diapositive fond couleur/image (taille, **effet Ken Burns** avec sens du zoom, voile + mode de fusion), contenu (titre, description, bouton, lien sur bouton / diapositive entière), style perso ; hauteur, balises, navigation (flèches, points), lecture auto, pauses, boucle, **transition glissement / fondu**, vitesse, **animation du contenu (bas, haut, droite, gauche, zoom)**.
