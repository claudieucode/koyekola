# 04k — Style V4, popups, boucles et tutoriels (lecture complémentaire)

_Articles lus le 2026-10-10 (corps, décalage 100 000)._

## Onglet Style V4 (Éditeur 4)
- **Arrière-plan** (/help/style-tab-background/) : couleurs, dégradés et images **empilables en calques** ; image : résolution, position, répétition, taille (auto, cover, contain, personnalisée), fixation (fixe / défile) ; dégradé : plusieurs couleurs avec positions, linéaire (angle 180 par défaut) ou radial (origine), retourner ; **découpe** (bordure, remplissage, contenu, texte). Calques : /help/add-a-layered-background/.
- **Effets** (/help/style-tab-effects/) : ombres multiples (intérieure / extérieure), opacité, **8 filtres + ombre portée** (flou, luminosité, contraste, teinte, saturation, niveaux de gris, inversion, sépia), **filtres d'arrière-plan**, transformations (déplacer, échelle, rotation, inclinaison), transition (200 ms par défaut ; durée par propriété = Pro), **modes de fusion**.
- **Position** (/help/style-tab-position/) : statique, relative, absolue, fixe, **sticky** (décalage, ne marche pas si le parent est en `overflow: hidden`) ; décalages, z-index, **décalage d'ancre** (hauteur d'un en-tête collant).
- **Taille** (/help/style-tab-size/) : largeur, hauteur, min, max, débordement (visible, masqué, auto), **ratio d'aspect**, ajustement et position de l'image.
- **Espacement** (/help/style-tab-spacing/) : marges et remplissages liés ou séparés ; contrôles en **propriétés logiques** (début / fin selon le sens d'écriture : /help/what-are-logical-properties/).
- **Typographie** (/help/style-tab-typography/) : famille, graisse, taille, alignement, couleur, interligne, interlettrage, espacement des mots, **colonnes + écart**, décoration, casse, **direction**, style, **contour du texte**.
- **Bordure** (/help/style-tab-border/) : types **solide, tirets, pointillé, double, gravé, ridge, inset, outset** ; épaisseur et rayon par côté / coin.
- **États** (/help/element-states/) : survol, focus, actif (+ « sélectionné » pour les onglets). **Conflits de styles** (/help/prioritize-conflicting-styles/) : la classe locale gagne toujours ; les autres classes par ordre dans le gestionnaire ; pastilles de couleur (rose = local, vert = actif, gris, orange = écrasé). **Réinitialiser** un réglage à la fois (/help/reset-style-settings/). **Liens imbriqués** (/help/nested-links/) : interdits en V4 (un élément cliquable dans un élément cliquable).
- **Classes** (/help/classes-in-elementor-2/, /the-elementor-editor-class-manager/) : classe locale + classes globales, conversion locale → globale, duplication, renommage, ordre, recherche, « où est-elle utilisée », filtres (inutilisées, vides, sur cette page). **Variables** (/help/variables/, /variables-manager/) : police, couleur de texte, taille (Pro) ; gestionnaire (créer, modifier, supprimer). **Rôles** (/help/user-roles-and-classes/) : l'administrateur fait tout ; l'éditeur utilise les classes sans en créer. **Export / import** des classes et variables : /help/how-to-export-and-import-variables-and-classes/.
- **Interactions V4** (/help/interactions/) : déclencheurs chargement, entrée dans la vue, **pendant le défilement**, survol, clic ; effets fondu / glissement / échelle, entrée ou sortie, direction, durée et délai ; **les mêmes interactions sur tous les écrans**.
- **Accordéon atomique** (/help/how-to-use-the-accordion-element-in-the-atomic-editor/) : état par défaut (premier ouvert / tous fermés), **nombre maximum de volets ouverts** (un / plusieurs), schéma FAQ « pour les robots d'IA », icônes. **Grille CSS** (/help/how-to-use-css-grid-in-the-atomic-editor/) : colonnes et lignes explicites (toute unité, `fr`), écarts, remplissage dense, étendue des enfants, contour de grille dans l'éditeur. **Boucle atomique** (/help/how-to-use-the-atomic-loop/, Pro) : requête, élément alterné, état vide, pagination.

## Popups (Pro, article « Configure a popup » — /help/popups/)
Déclencheurs : **chargement après N secondes**, **défilement** (% de la page), défilement jusqu'à un élément, **clics**, **inactivité**, **intention de sortie** ; règles avancées : nombre de pages vues / de sessions, **limite d'affichages** (mémorisée), source de trafic, visiteurs connectés (rôles), **appareils** ; fermeture : empêcher la fermeture par le fond ou Échap, **fermeture automatique**, bouton de fermeture différé ; désactiver le défilement derrière ; conditions d'affichage (pages). Ouverture manuelle : lien (`Actions › Popup`), sélecteur CSS (`a[href="#id"]`), formulaire envoyé, élément de menu. Types d'exemples : **fly-in** (coin bas droit à 80 % de défilement), **plein écran** (30 s d'inactivité), **barre du bas** (une fois par visiteur, sans fermeture), **glissement** (porte d'âge, bouton de fermeture masqué), **opt-in** (intention de sortie), **verrou de contenu** (oui / non, redirection), **cookies** (bandeau « Accepter » : ne stocke pas le consentement, **non conforme RGPD** selon l'article), **Hello Bar**.

## Boucles et requêtes
Grille de boucle : **modèle alterné** à une position donnée, élément statique ou unique, étendue de colonnes (/help/how-do-i-add-an-alternate-template-in-a-loop-grid/) ; **pagination** (aucune par défaut ; numéros, précédent/suivant, charger au clic, défilement infini ; rechargement ou AJAX ; pagination individuelle : /help/paginate-loop/) ; requêtes (source, inclure / exclure par terme, auteur, date, tri ; **ID de requête** réutilisable : /help/create-queries/, /customize-items-in-loop/).
