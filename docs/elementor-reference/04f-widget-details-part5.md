# 04f — Réglages des widgets (suite, partie 5)

_Articles lus le 2026-10-10._

- **Google Maps** (/help/google-maps-widget/) : lieu, zoom, hauteur ; filtres CSS normal/survol avec transition. Exige une **clé API Google Maps Embed** (Elementor → Réglages → Intégrations).
- **HTML** (/help/html-widget/) : zone acceptant HTML, CSS, shortcodes et JS. **Avertissement officiel : le code peut contenir un logiciel malveillant ; accès limité aux administrateurs** (modifiable par le gestionnaire de rôles).
- **Panier de menu** (/help/menu-cart-widget-pro/) : icône (panier, cabas, sac ; léger/moyen/plein), indicateur d'articles, sous-total, panier latéral ou mini-panier (au clic / survol), boutons Voir le panier / Paiement, ouverture automatique. **Exige WooCommerce.**
- **Menu (conteneurs imbriqués)** (/help/the-menu-widget/) : éléments (titre, lien, contenu déroulant, icône, ID CSS), largeur du contenu (pleine / ajustée), disposition horizontale / déroulante, position, indicateur de sous-menu, ouverture au clic / survol + animation, bouton de bascule, défilement horizontal, **point de rupture du menu déroulant** (aucun, mobile, tablette) ; un sous-menu est un conteneur (peut contenir un autre menu) ; style très complet. Marqué **expérimental**.
- **Off-Canvas** (/help/off-canvas-widget/) : mode d'édition, position H/V, largeur, hauteur ; animations d'entrée et de sortie ; **ne pas fermer au clic sur le fond / à Échap, désactiver le défilement de la page** ; voile (couleur, image).
- **Bouton flottant** (/help/floating-button/) : plateforme (WhatsApp, Messenger, e-mail, SMS, Viber, Skype), pastille de notification, barre du haut (nom, titre, photo), bulle de message (heure 12/24 h, animation de frappe), bouton d'envoi, boîte de chat (largeur, coins, ombre, animation) ; position H/V avec décalage. **Conditions d'affichage : Pro.**
- **Table des matières** (/help/table-of-contents-pro/) : titre + balise, inclure (ancres par balises, conteneur), exclure (sélecteur), puces ou numéros, retour à la ligne, **boîte réductible** (icônes, réduite sur…), vue hiérarchique, sous-éléments repliables ; style de la boîte, de l'en-tête, des ancres.
- **Carrousel média** (/help/media-carousel-widget-pro/) : habillages **Carrousel, Diaporama (miniatures), Coverflow** ; diapositives image ou vidéo ; effets Slide / Fondu / Cube ; recouvrement (aucun, texte, icône) ; ajustement de l'image (couvrir, contenir, auto) ; style de la visionneuse.
- **Galerie de base** (/help/basic-gallery-widget/) : images, résolution, **colonnes 1–10**, légende (aucune / celle de la pièce jointe), lien (fichiers, page de pièce jointe, aucun), visionneuse oui/non, ordre (défaut / aléatoire) ; espacement, bordure, rayon, légende.
- **Portfolio** (/help/portfolio-widget-pro/) : colonnes, nombre, résolution, ratio, titre + balise ; **requête** (sources articles, pages, types personnalisés, manuel, requête courante, associés ; inclure / exclure par terme ou auteur, date, tri, ordre, décalage, éviter les doublons, ID de requête) ; **barre de filtres par taxonomie** ; style des éléments, du voile, des filtres.
