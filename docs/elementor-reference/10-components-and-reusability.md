# 10 — Styles, composants et réutilisation

_Vérifié le 2026-10-10 (recherches elementor.com ; articles complets non lus sauf mention)._
- **Éléments globaux** : menu contextuel « Enregistrer comme global » (widgets) — confirmé dans l'article du menu contextuel ; édition et détachement : **non lus**.
- **Composants (V4)** : sections réutilisables synchronisées sur tout le site ; on peut exposer des parties du contenu pour une édition par instance. **Pro** (résultats de recherche).
- **Classes et variables (V4)** : voir 06.
- **Modèles** : « Enregistrer comme modèle » (conteneur, section) ; bibliothèque (Ctrl/Cmd+Maj+L) ; export `.json` des en-têtes/pieds ; Kits (modèles + pages + fenêtres + réglages du site) importables par l'admin ou `wp elementor kit import` (options `--include=content,templates,site-settings`). Sources : https://elementor.com/help/import-and-export-elementor-website-templates/, https://developers.elementor.com/docs/cli/kit-import (page ancienne : syntaxe à revérifier).
- **Styles enregistrés / application partielle** : l'enregistrement des styles par l'utilisateur dans l'éditeur classique **n'est pas documenté dans les pages lues** ; les classes globales V4 jouent ce rôle.
## Non vérifié
Synchronisation des éléments globaux, résolution de conflits de styles, dépendances.
