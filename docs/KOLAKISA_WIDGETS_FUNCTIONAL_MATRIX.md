## Règle de classement appliquée

* **VALIDÉ** : cycle de vie dans l'éditeur, enregistrement → publication → rendu, 8 largeurs × 2 contenus, accessibilité de base et réglages de contenu réussis, et — s'il est interactif — interaction ou liens publiés réussis dans cette mission.
* **PARTIEL** : au moins un critère n'est pas éprouvé (service tiers non joignable dans les tests, données du site non fournies, formation / formulaire réels requis) sans échec constaté.
* **DÉFECTUEUX** : un test de cette mission a échoué sur ce widget et le défaut n'est pas corrigé.
* **NON TESTÉ** : preuves insuffisantes.

Aucun widget n'est classé « ABSENT » ou « BLOQUÉ » par cette règle : les lacunes de fonctions (comparées à Elementor) sont dans `KOLAKISA_WIDGETS_GAP_ANALYSIS.md`.
