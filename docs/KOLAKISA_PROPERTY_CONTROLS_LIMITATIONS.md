# Limites et risques restants

* **L1 — Grammaire de longueurs fermée.** Pas de `calc()`, `clamp()`, `min()`, `max()`, `minmax()`, `ch`, `vmin`, `vmax`, ni de mots-clés CSS globaux (`inherit`, `initial`, `unset`). Choix de sécurité : une valeur libre pourrait casser la page ou en détourner l'affichage. Conséquence : certaines mises en page fluides (`clamp(1rem, 2vw, 3rem)`) ne sont pas exprimables dans les réglages ; elles passent par le CSS personnalisé de l'élément. Une évolution demanderait un analyseur d'expressions validé.
* **L2 — Changement d'unité sans conversion.** Passer de `px` à `rem` garde le nombre (12px → 12rem) et l'annonce par un message ; ce n'est pas une conversion. Voulu (prévisible), mais différent d'Elementor sur ce point.
* **L3 — « Nouvel onglet » et `https://`.** Le réglage n'est conservé que pour une adresse `https://`. Une adresse relative (`/catalogue`) ou `http://` l'écarte à l'enregistrement ; l'interface l'indique dans le libellé mais laisse la case cochable (la rendre dynamique exigerait de réécouter le champ d'adresse).
* **L4 — Champs en paire.** Bouton de fenêtre modale, verso de carte : un texte sans adresse est écarté sans message à l'enregistrement (le diaporama, lui, affiche un refus). À harmoniser avec un message commun si le besoin se confirme ; non fait ici pour ne pas rendre invalides des pages existantes.
* **L5 — Menus d'unités volontairement restreints.** Ex. `vh` absent pour une largeur ; le serveur l'accepterait. Taper une unité absente du menu est refusé avec un message.
* **L6 — Décoration du texte, ombres de texte.** Décoration : aucune / soulignée / barrée (pas de style ni de couleur) ; ombre du texte : 5 préréglages (pas d'ombre de texte personnalisée).
* **L7 — Matrice de contenu partielle par défaut.** `tests/controles-contenu-navigateur.test.js` parcourt 16 types représentatifs ; les 79 types instanciables ont été parcourus **une fois** pendant l'audit (109 listes, 118 cases, 221 champs ; aucun contrôle sans effet silencieux hors les cas L3/L4), mais le parcours complet (≈ 50 min) n'est pas rejoué à chaque fois (`CONTENU_COMPLET=1`).
* **L8 — Chrome seulement.** Les parcours navigateur ont été exécutés avec Chrome sur une machine de 2015 (60 Hz) ; Safari et Firefox n'ont pas été testés.
* **L9 — jsdom.** Les suites en « navigateur simulé » ne s'exécutent que si `jsdom` est installé (`npm install --no-save jsdom`) ; elles étaient ignorées dans l'environnement de travail et ont dérivé avant ce chantier. Elles ont été exécutées ici (jsdom installé hors du projet) et réparées ; pour qu'elles ne dérivent plus, il faut les exécuter régulièrement avec jsdom.
* **L10 — Mesures de performance.** Une machine, trois répétitions par scénario, bruit visible (±30 % sur certaines latences) : les comparaisons « avant / après » établissent l'absence de régression, pas un gain.
