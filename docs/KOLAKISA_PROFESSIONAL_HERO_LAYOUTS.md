# Hero

15 layouts de hero, 12 structures distinctes (test : signatures structurelles). Familles : Split, Fullscreen (100vh), Image Background (80vh), Typography-led, Product, Editorial, Minimal, Asymmetric, Layered, Creative, Corporate. Le Video Hero n'est pas généré.
Contrôles : taille du titre selon la longueur (display 72 px → md 36 px, jamais de troncature ; réduit sur tablette/mobile, ≥ 28 px), largeur du texte (`32/40/48/64 rem`), voile de contraste `#0b2a40b3` + texte blanc sur image de fond, boutons principal/secondaire, hauteur compactée sur téléphone (70 vh → 60 vh), un seul H1 par page (test).
Sélection : le secteur et la direction orientent la famille (restaurant/voyage → immersif ; avocat/finance → corporate/minimaliste), les contraintes écartent les layouts sans image.
