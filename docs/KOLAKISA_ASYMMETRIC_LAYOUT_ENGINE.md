# Asymétrie

Règle : l'asymétrie sert la hiérarchie. Le rapport maximal entre colonnes est borné (analyseur d'équilibre : > 4:1 signalé, test sur chaque hero) ; une colonne étroite ne porte que des repères (numéros) ou rien de long.
Compositions : image 65 % / texte 35 % (`Image-led Editorial`, 13:7) ; grande image haute + texte + vignette (`Asymmetric Editorial`, `Layered Visual`, version miroir) ; carte héroïne 2×2 (`Creative Asymmetric Grid`) ; texte superposé à l'image (`Overlapping Composition`, `Layered Hero`) ; titre éditorial + colonne étroite (`Magazine`).
Sur tablette et mobile, les compositions se réorganisent (carte sous l'image, vignette secondaire masquée) : voir RESPONSIVE.
