# Responsive

Points de rupture : ceux du site (réglages natifs, jamais modifiés). Réglages par écran (`settings.responsive.tablet|mobile`) : tailles de h1-h3 et du texte, marge latérale, espacements L et XL. Le mobile n'est pas une réduction homothétique : texte fixé à 16 px, marges 16 px, espacements recalculés à part (×0,6 et ×0,5), titres bornés. Contrôles : bureau > tablette > mobile pour h1, texte mobile ≥ 16, titre mobile ≥ 26. Les colonnes de cartes s'empilent par le rendu natif.
