# Variantes

`variants()` compose chaque layout éligible puis garde une variante par **signature structurelle** (types, pistes, portées, sens du flex ; ni textes ni identifiants). Pour 5 services : grille de cartes, liste éditoriale, asymétrique, numérotée (+ vitrine illustrée si chaque élément a une image).
Écran : prévisualiser (filaire, 3 écrans), comparer (2 à N côte à côte), choisir → proposition (aperçu, impact, remarques) → appliquer (brouillon) → annuler. Le contenu d'origine est conservé (`mk_layout_sections`) : régénérer une section n'oblige pas à ressaisir les textes. Une section retouchée à la main exige une confirmation, puis l'autorisation explicite de l'élément.
