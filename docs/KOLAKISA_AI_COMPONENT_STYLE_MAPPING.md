# Correspondance décisions → composants

| Composant | Réglages natifs utilisés |
|---|---|
| Boutons | fond/texte normal-survol-actif, focus, rayon, padding, hauteur, ombre, bordure |
| Cartes | rayon, ombre (selon l'ambiance) |
| Formulaires | fond, texte, bordure (≥ 3:1), rayon, padding, focus, placeholder, libellé, accent |
| Images | rayon |
| Liens | couleur, survol, soulignement |
| Navigation | non générée (menus : Apparence → Menus ; pas de réglage de style natif) |
Aucune propriété de widget n'est inventée : tous les chemins sont ceux du catalogue du personnalisateur ; le personnalisateur réel valide chaque valeur à l'écriture (`cleanChanges`).
