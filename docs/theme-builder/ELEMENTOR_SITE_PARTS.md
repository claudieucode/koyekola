# Elementor — types de modèles (parties de site)

| Partie | Rôle (documenté) | Emplacement du thème remplacé |
|---|---|---|
| Header | En-tête global | `header.php` (emplacement `header`) |
| Footer | Pied de page global | `footer.php` (`footer`) |
| Single (page / article) | Mise en page globale d'un contenu individuel ; inclut la page 404 côté emplacement | `singular.php`, `single.php`, `page.php`, `attachment.php`, `404.php` (`single`) |
| Archive | Listes : archives, taxonomies, auteurs, dates, recherche | `archive.php`, `taxonomy.php`, `author.php`, `date.php`, `search.php` (`archive`) |
| Sidebar (article d'aide dédié) | Barre latérale | — |
| Single Product | Fiche produit WooCommerce | — |
| Product Archive | Boutique / catégories de produits | — |
| Sticky transparent header | Variante de comportement d'en-tête | — |
Articles d'aide supplémentaires cités : créer/modifier header, footer, pages individuelles, archives, sidebar, produit unique ; « ajouter un modèle à une page » ; bibliothèque de modèles (locale et cloud).

## Types demandés par Kolakisa vs Elementor
Header, Footer, Page individuelle, Article individuel, Archives, Résultats de recherche, 404, Produit individuel, Archives produits, pages boutique/panier/paiement/compte, modèles personnalisés. (Elementor expose panier/paiement/compte via WooCommerce Pro ; non détaillé dans les pages lues.)
