# Catalogue des 100 modèles de pied de page

**Généré par code** (`node scripts/documenter-pieds.js`) à partir de `src/themeBuilder/catalog/footer/familles/*.js`. Ne pas modifier à la main.

- Modèles : 100 en 15 familles (toutes construites).
- Similarité de structure entre deux modèles (0 = rien en commun, 1 = identique ; seuil d'échec du test : 0,85) : **maximum 0.723**, moyenne 0.275, paires > 0,70 : 2, > 0,75 : 0, > 0,80 : 0, > 0,85 : 0 (sur 4950 paires).
- « Rangées » = bandes empilées ; « Colonnes » = zones de chaque rangée (ex. 4/2). « Accordéon » = rubriques qui se déplient sur mobile. « Voisin » = modèle le plus proche et sa similarité.
