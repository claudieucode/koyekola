# Guide d'administration (Site Web → site → Boutique)

Onglets : Produits · Catégories · Avis · Rendez-vous · Listes cadeaux · Abonnements · Commandes · Rapports · Factures · Accès membre · Clients · **Paiements** · **Taxes et expédition** · Réglages.

- **Ouvrir la boutique** : activer le module Commerce du site (équipe), saisir livraison, taxes si besoin, **Paiements** (identifiants), puis cocher « boutique ouverte » et les moyens de paiement dans Réglages.
- **Produits** : simple, variable (générateur de variantes), numérique (fichiers à télécharger) ; duplication ; classes de taxe/expédition ; actions groupées (publier, brouillon, archiver, supprimer).
- **Commandes** : statuts (préparation, expédiée, terminée), numéro de suivi, notes internes, remboursements réels (partiels ou totaux, remise en stock en option), factures/avoirs, actions groupées, **création manuelle** (vente par téléphone).
- **Coupons** (Réglages) : pourcentage ou montant ; minimum, dates, limites, produits/catégories ; **livraison offerte** ; **promotion automatique** (sans code). Un coupon utilisé ne se supprime pas, il se désactive. Pas de cumul de promotions (la plus avantageuse s'applique ; un code valide a la priorité).
- **Clients** : fiche (commandes, total dépensé), exonération de taxe, export et effacement des données (RGPD).
- **Rapports** : chiffres de période, ventes par jour, meilleurs produits, stock bas, paniers abandonnés, exports CSV.
- **Theme Builder** : modèles Panier, Validation de commande, Commande reçue, Compte client (100 chacun) ; éléments de fiche produit et mini-panier dans le Page Builder.
