# Programme 21.4 — limites et reste à faire

- **Pas de Site Planner (21.3)** : le contrat de plan v1 est défini ici ; le plan par défaut vient du type de site de l'assistant 20.6.
- **Composants absents du CMS** (donc non générés) : galerie/grille, tableau, carte, listes dynamiques (articles, produits, biens), tarifs dédiés, icônes dans les cartes. Les pages de boutique/panier/commande ne sont pas générées.
- **Formulaire de contact** : la section est créée, mais le formulaire doit être associé à la page dans ses réglages avant publication.
- **Images** : jamais ajoutées sans que le plan les fournisse.
- **Responsive** : seuls les attributs natifs de section (espacement, fond, alignement, largeur) et les colonnes sont posés ; pas de styles par écran (`styles`) ni de `hideOn` générés.
- **Éléments globaux** (en-tête, pied de page, menu) : non générés, ceux du Theme Builder s'appliquent. Les widgets du Page Builder (sections libres) ne sont pas utilisés.
- **Qualité du texte IA** non évaluée ; relecture obligatoire (signalée à l'écran).
- **Non vérifié** : rendu visuel dans un navigateur.
## Prérequis pour 21.5
Site Planner produisant le contrat v1 ; sélecteur de médiathèque pour les images ; association automatique d'un formulaire de site ; éventuellement sections libres (`layout`) si une mise en page plus riche est requise.
