# Règles typographiques

- Polices : uniquement celles que le moteur charge (`tokens.FONTS` : Figtree, Bricolage Grotesque, système, Georgia, monospace) avec leurs piles de repli. Associations : moderne, classique, éditorial, neutre, système. Les polices téléversées d'un site ne sont pas utilisées (voir limites).
- Échelle modulaire : texte 16/17/18 px selon la densité ; rapport 1,2 (minimaliste) à 1,333 (créatif) ; h1 plafonné à 64 px ; hiérarchie strictement décroissante (contrôle `typography.check`).
- Interlignes : 1,1 (h1) à 1,4 ; texte 1,6 (1,7 en densité aérée). Graisses : 400, 600/700/800 (valeurs acceptées par le moteur).
- Responsive : titre tablette ×0,85, mobile ×0,62 (min 28 px) ; texte mobile 16 px ; vérifié.
- Langues : les 6 langues de l'assistant sont du latin accentué, couvert par les polices intégrées.
