## Limites et écarts assumés

- **Facebook Comments** : exige un identifiant d'application Facebook et le chargement du script externe Facebook ; Kolakisa n'en charge aucun (sécurité, performance). Bloqué par une dépendance.
- **Shortcode** : notion WordPress ; un shortcode exécute du code côté serveur. Remplacé par les étiquettes dynamiques et le HTML sécurisé. Non implémenté par choix de sécurité.
- **Template** : l'équivalent existe sous un autre chemin — onglet « Blocs » → Composants (insertion d'un composant enregistré) ; ce n'est pas une entrée de la liste « Éléments », d'où l'absence de clé dans la table.
- **Stripe / PayPal** : liens de paiement HÉBERGÉS par le prestataire (liste blanche de domaines). Pas de clé API stockée, pas de script externe, pas de création de produit ni de prix dans Kolakisa, contrairement aux widgets Elementor qui s'intègrent à l'API du prestataire.
- Le contenu détaillé des contrôles de chaque widget Elementor n'a pas été relu intégralement lors de cette intervention ; la référence détaillée précédente reste dans `docs/elementor-reference/` (non rouverte ici).
